# 🌍 Travel with Globetrek

A PHP and MySQL-based tourism and travel booking web system developed to help users explore destinations, view travel packages, make bookings, manage payments, and access travel-related services through a centralized web platform.

## 📌 Project Overview

**Travel with Globetrek** is a tourism and travel management web application designed to provide an online platform for customers and staff.

The system includes destination information, travel packages, customer accounts, booking management, payment-related features, reviews, inquiries, and administrative management.

├── admin/

## 🗄️ Database

The project includes a MySQL database configuration and a `database` folder for database-related files.

The local database connection is configured for a XAMPP development environment.

## ⚙️ Installation

### Requirements

- XAMPP
- Apache
- MySQL
- PHP
- phpMyAdmin
- Modern web browser

### Setup

1. Clone or download the repository.
2. Place the project inside the XAMPP `htdocs` folder.
3. Start **Apache** and **MySQL** using XAMPP.
4. Create the required MySQL database.
5. Configure the database connection in:

```text
includes/db.php
```

6. Open the project through the local XAMPP server.

Example:

```text
http://localhost/GlobeTrek/
```

> This project is configured for a local XAMPP development environment. Login credentials and private runtime data are not published in this repository.
